EU Unemployment Dashboard
Spain's unemployment rate has stayed 3-4x Czechia's for over a decade — even as the EU average fell by a third since 2003.


An interactive dashboard exploring unemployment rates across EU countries (2003–2025), built with Streamlit and Plotly, using live data from Eurostat.



What it shows
KPI summary: EU average now vs. the start of the series, highest/lowest country, and the gap between them
Trend chart: compare unemployment rates across selected countries over time
Ranking chart: bar chart of all countries for the latest year
Heatmap: country × year view showing the 2013 euro-crisis wave and the 2020 COVID bump
Data
Source: Eurostat une_rt_a — annual unemployment rate, ages 15–74, % of active population. Fetched live via the eurostat Python package, cached for 24h.
